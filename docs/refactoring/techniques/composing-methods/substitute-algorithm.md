# Substitute Algorithm

**URL:** https://refactoring.guru/substitute-algorithm

## Problem
You want to replace an existing algorithm with a new one.

## Solution
Replace the body of the method that implements the algorithm with a new algorithm.

## Why Refactor
- **Simplicity:** You might find a much simpler or more efficient way to solve a problem as you learn more or find better libraries.
- **Clarity:** If the current implementation is too complex and a cleaner version exists, swapping it entirely is often better than incremental changes.
- **Performance:** Replacing an inefficient algorithm with a faster one.
