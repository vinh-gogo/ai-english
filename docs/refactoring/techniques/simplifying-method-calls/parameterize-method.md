# Parameterize Method

**URL:** https://refactoring.guru/parameterize-method

## Problem
Several methods do similar things but with different values, numbers, or operations.

## Solution
Combine these methods by using a parameter that will pass the necessary special value.

## Why Refactor
- **Reduce Duplication:** Merges multiple similar methods into one.
- **Flexibility:** Makes the method more versatile.
