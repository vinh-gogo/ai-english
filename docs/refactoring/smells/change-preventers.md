# Change Preventers

**URL:** https://refactoring.guru/refactoring/smells/change-preventers

## Description
These smells mean that if you need to change something in one place in your code, you have to make many changes in other places too. As a result, program development becomes much more complicated and expensive because a single modification triggers a cascade of necessary updates.
