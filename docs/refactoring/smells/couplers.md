# Couplers

**URL:** https://refactoring.guru/refactoring/smells/couplers

## Description
All the smells in this group contribute to excessive coupling between classes or show what happens if coupling is replaced by excessive delegation. They indicate that classes are too intimately tied to one another, making it difficult to modify or reuse them independently.
