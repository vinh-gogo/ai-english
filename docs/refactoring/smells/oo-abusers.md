# Object-Orientation Abusers

**URL:** https://refactoring.guru/refactoring/smells/oo-abusers

## Description
All these smells represent an incomplete or incorrect application of object-oriented programming principles. They often manifest as structures that fail to take full advantage of polymorphism, inheritance, or encapsulation, leading to rigid or confusing designs.
