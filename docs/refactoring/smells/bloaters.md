# Bloaters

**URL:** https://refactoring.guru/refactoring/smells/bloaters

## Description
Bloaters are code, methods, and classes that have increased to such gargantuan proportions that they are hard to work with. Usually, these smells do not crop up right away; rather, they accumulate over time as the program evolves, especially when no effort is made to eradicate them.
