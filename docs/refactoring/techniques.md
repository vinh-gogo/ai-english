# Refactoring Techniques

**URL:** [https://refactoring.guru/refactoring/techniques](https://refactoring.guru/refactoring/techniques)

Refactoring is a systematic process of improving code without creating new functionality. It transforms "dirty code" into "clean code."

## Categories

Detailed documentation for each category:

- [**Composing Methods**](techniques/index.md#composing-methods): Streamlining methods and removing duplication.
- [**Moving Features between Objects**](techniques/index.md#moving-features-between-objects): Safely moving functionality between classes.
- [**Organizing Data**](techniques/index.md#organizing-data): Handling data and replacing primitives with objects.
- [**Simplifying Conditional Expressions**](techniques/index.md#simplifying-conditional-expressions): Combating complicated logic.
- [**Simplifying Method Calls**](techniques/index.md#simplifying-method-calls): Making interfaces easier to understand.
- [**Dealing with Generalization**](techniques/index.md#dealing-with-generalization): Moving functionality along the inheritance hierarchy.

For a full list of techniques, see the [**Techniques Index**](techniques/index.md).
